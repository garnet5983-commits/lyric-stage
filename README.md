# LYRIC STAGE

スマートフォン向け、端末内で動くMV字幕エディターの試作版。音楽と背景画像・動画を読み込み、歌詞を改行ごとにフレーズへ分割します。`【ここ】` と囲むとその語を大きく見せる構図にできます。LRC形式の時刻付き歌詞も読み込めます。タイミングは均等な仮配置から再生に合わせて記録・調整します。

## 主な機能

- 縦 9:16／横 16:9 のプレビューとフルHD書き出し
- 31種のモーション演出と5種の構図、8種の図形パターン（同心円、グリッド、透視トンネル、モアレ、六角、プリズム、帯、切り抜き文字）（映画的ワイプ、文字ごとの出現、ネオン、残像、波打ち、跳ねる文字、グリッチなど）と4種のMVテーマと日本語Webフォント30種
- テーマの配色を保つ「お任せ演出」と、各行の「演出を見る」プレビュー、動きの強さ、フレーズ別のフォント・文字色
- 曲の強い拍を端末内で任意解析し、強調・光演出に反映。画像背景の緩やかなカメラ移動
- ブラウザ内の音楽・映像を使うプレビューと動画書き出し（端末の MediaRecorder 対応に依存）
- 編集データの JSON 保存と再読込（素材ファイルは再選択）
- PWA のオフライン起動。追加フォントは選択時に歌詞で使用する字形だけを Google Fonts から取得し、選んだフォントのデータを端末内に保存。初回の読み込みにはネット接続が必要

## 使い方

1. `index.html` を HTTPS の静的ホスティングで公開する（GitHub Pages など）。ローカル検証は `python3 -m http.server 8000` で起動する。
2. スマホで公開URLを開き、共有メニューからホーム画面に追加する。初回接続後はアプリ本体をオフラインで起動できる。
3. 音楽と任意の背景を選び、歌詞を貼ってフレーズを作る。
4. 曲を再生し、各フレーズの頭で「再生位置で次のフレーズを記録」を押す。必要なら開始秒数を直す。
5. 演出を選択し「フルHD動画を書き出す」を押す。書き出しは実時間で進むので画面を開いたままにする。

## 現時点の制約

歌声から歌詞を自動認識・正確に同期する機能はありません。貼り付けた歌詞を改行ごとに自動分割し、再生に合わせてタイミングを記録する方式です。ブラウザのメディア録画 API が使えない端末では動画を書き出せません。MP4 と WebM のどちらになるかは端末の対応形式によります。長い動画のフルHD書き出しは端末性能やメモリ、OSのバックグラウンド制限に影響されます。歌詞の意味や歌声の正確な位置をAI解析する機能はありません。未指定の強調語は句読点と長さから仮に選びます。曲のテンポと語ごとのタイミングは自動同期しません。音楽・映像ファイルは端末から読み込み、アプリからサーバーへ送信しません。

## 追加フォントの通信

日本語Webフォント30種は Google Fonts 提供です。初回選択時にフォント名と歌詞に登場する文字を Google Fonts に送信し、字形ファイルを取得します。曲・背景ファイルは送信しません。選択した字形はブラウザのキャッシュに保存します。オフライン中に新しい文字が必要になると書き出し前に接続を求めます。iPhone のストレージ整理などでブラウザのキャッシュが消えた場合も再取得が必要です。長い歌詞でランダムフォントを使う場合、初回の準備に時間がかかります。
