# LYRIC STAGE

スマートフォン向け、端末内で動くMV字幕エディターの試作版。音楽と背景画像・動画を読み込み、歌詞を改行ごとにフレーズへ分割します。LRC形式の時刻付き歌詞も読み込めます。タイミングは均等な仮配置から再生に合わせて記録・調整します。

## 主な機能

- 縦 9:16／横 16:9 のプレビューとフルHD書き出し
- 31種のモーション演出（映画的ワイプ、文字ごとの出現、ネオン、残像、波打ち、跳ねる文字、グリッチなど）と4種のMVテーマ
- テーマの配色を保つ「お任せ演出」と、各行の「演出を見る」プレビュー、動きの強さ、フレーズ別のフォント・文字色
- 曲の音量変化に反応する一部の光演出と、画像背景の緩やかなカメラ移動
- ブラウザ内の音楽・映像を使うプレビューと動画書き出し（端末の MediaRecorder 対応に依存）
- 編集データの JSON 保存と再読込（素材ファイルは再選択）
- PWA のオフライン起動。初回の読み込みにはネット接続が必要

## 使い方

1. `index.html` を HTTPS の静的ホスティングで公開する（GitHub Pages など）。ローカル検証は `python3 -m http.server 8000` で起動する。
2. スマホで公開URLを開き、共有メニューからホーム画面に追加する。初回接続後はアプリ本体をオフラインで起動できる。
3. 音楽と任意の背景を選び、歌詞を貼ってフレーズを作る。
4. 曲を再生し、各フレーズの頭で「再生位置で次のフレーズを記録」を押す。必要なら開始秒数を直す。
5. 演出を選択し「フルHD動画を書き出す」を押す。書き出しは実時間で進むので画面を開いたままにする。

## 現時点の制約

歌声から歌詞を自動認識・正確に同期する機能はありません。貼り付けた歌詞を改行ごとに自動分割し、再生に合わせてタイミングを記録する方式です。ブラウザのメディア録画 API が使えない端末では動画を書き出せません。MP4 と WebM のどちらになるかは端末の対応形式によります。長い動画のフルHD書き出しは端末性能やメモリ、OSのバックグラウンド制限に影響されます。歌詞の内容から意味や歌声の位置を解析して演出を自動設計する機能はありません。音楽・映像ファイルは端末から読み込み、アプリからサーバーへ送信しません。
